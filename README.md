# 咸康（台灣）分支｜族人行動資料填報工具

此 repository 僅存放族人端空白填報程式，不存放 MASTER、族人回傳資料、照片或其他家族私人資料。

目前階段：v0.10 行動填報實測。

核心流程：LINE 點網址 → 填寫多人 → 手機本機產生 Excel／ZIP → 原生分享選單 → LINE 傳給 Mars。

v0.10 重點：保留學歷、論文三分類、健康隱私、祖籍簡化與多筆工作功能；依第一副主編 2026-09-09 實測修正，軍旅／職業軍人生涯統一歸入「工作／職務」，不再另外強調「軍職」。一般義務役／替代役不要求填。公職仍可獨立選填並採保守揭露。表單明確提醒不要填現役部隊番號、精確駐地、任務／行動內容、兵籍號或人事編號、內線／聯絡資訊、承辦案件細節、內部系統名稱／帳號、安全查核、未公開組織／編制或其他機敏資料。

配偶姓名也新增防混填提示：主要配偶欄只填一個主要姓名；同一人另有中文名、英文名或曾用名時，應放到該人物的「曾用名／其他名字」，不要把兩個姓名擠在同一格。
