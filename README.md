# 咸康（台灣）分支｜族人行動資料填報工具

此 repository 僅存放族人端空白填報程式，不存放 MASTER、族人回傳資料、照片或其他家族私人資料。

目前階段：v0.8 行動填報實測。

核心流程：LINE 點網址 → 填寫多人 → 手機本機產生 Excel／ZIP → 原生分享選單 → LINE 傳給 Mars。

v0.8 重點：一般人物以最高學歷為主；碩博士可從大學一路填至最高學歷與學位論文。國小／國中／高中高職完全選填，活人完整校名原則不公開；若要保留求學遷徙，可只填所在地／求學地區。本人學位論文、本人學術著作／研究論文、本人指導之他人論文分開；工作／職務可新增多筆，不設固定 4～5 筆上限。v0.7 已完成的祖籍選填、前妻／前夫、健康隱私、古人字號婚配與兵役提示全部保留。
