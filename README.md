# 咸康（台灣）分支｜族人行動資料填報工具

> **專案資料重啟／接班請先閱讀：** [重啟與復原指引（公開安全版）](docs/RESTART_AND_RECOVERY.md)。正式 MASTER v1.0、完整 ZIP 及來源附件存放於私有 Google Drive，不在此公開儲存庫。

此 repository 僅存放族人端空白填報程式，不存放 MASTER、族人回傳資料、照片、Email、登入資料或其他家族私人資料。

目前狀態：正式確定版。技術基底為 v0.11.1（Android／LINE 相容修正）。

2026-09-19 專案資料層已更新；本次屬私人 MASTER／私人系統資料更新，不改變族人端空白填報流程，因此 `index.html` 功能版本維持 v0.11.1。私人 MASTER 與登入聯絡資料仍不提交至 GitHub。

核心流程：LINE 點網址 → 填寫多人 → 手機本機產生 Excel／ZIP → 原生分享選單 → 使用者手動選 LINE → Mars → 送出。這不是自動上傳；只有在 LINE 聊天室看到檔案訊息，才算完成回傳。若內建瀏覽器不支援檔案分享，系統會改成下載 Excel／ZIP，之後仍需自行透過 LINE 傳給 Mars。

v0.11 重點：正式新增「外文姓名」獨立欄位。中文姓名與外文姓名為平行資訊；有中文姓名時，中文姓名作本中文族譜主要顯示，外文姓名另行保存與顯示，不放進「曾用名／其他名字」。外文姓名只知道完整字串時直接原樣填寫，不要求族人判斷姓、名或中間名，也不得自行猜拆。

外文姓名的具名案例與待查註記只保留於私人來源／MASTER，不在此公開儲存庫列出。當只知道完整外文姓名時，須原樣保留，不推測拆分姓與名。

沿用 v0.10 規則：軍旅／職業軍人生涯歸入「工作／職務」，不另外強調「軍職」；一般義務役／替代役不要求填。公職仍可獨立選填。表單明確提醒不要填現役部隊番號、精確駐地、任務／行動內容、兵籍號或人事編號、內線／聯絡資訊、承辦案件細節、內部系統名稱／帳號、安全查核、未公開組織／編制或其他機敏資料。
