# 咸康（台灣）分支｜族人行動資料填報工具

此 repository 僅存放族人端空白填報程式，不存放 MASTER、族人回傳資料、照片或其他家族私人資料。

目前階段：v0.9 行動填報實測。

核心流程：LINE 點網址 → 填寫多人 → 手機本機產生 Excel／ZIP → 原生分享選單 → LINE 傳給 Mars。

v0.9 重點：保留 v0.8 的學歷、論文三分類與多筆工作功能，並把「軍職」「公職」恢復為獨立可填類型。軍職／公職只收適合家族保存的概括資料；一般義務役／替代役不要求填。表單明確禁止填寫現役部隊番號、精確駐地、任務／行動內容、兵籍號或人事編號、內線／聯絡資訊、承辦案件細節、內部系統名稱／帳號、安全查核、未公開組織或其他機敏資料。活人／現職軍公職細節採保守揭露，沒有明確完整揭露授權時，閱讀版只顯示概括「曾有軍職經歷／曾有公職經歷」。
